           DIGITAL TOUCHPAD — UNIVERSAL COMPANION RECEIVER
                     Works on ANY Windows PC, Mac, or Linux
================================================================

1. ON WINDOWS PC / LAPTOP (ZERO CONFIGURATION):
   • Double-click "start-receiver.bat".
   • It launches the receiver IN THE BACKGROUND on port 8443.
   • YOU CAN SAFELY CLOSE THE WINDOW! The receiver keeps running in the background.
   • To stop it anytime, simply double-click "stop-receiver.bat".

2. ON APPLE MACBOOK / MAC DESKTOP:
   • Open Terminal in this folder.
   • Run: node receiver/server.js
   • Automatically enables macOS Quartz/AppleScript injection, Spotlight, & Mission Control.

3. ON LINUX (UBUNTU / FEDORA / ARCH):
   • Open Terminal in this folder.
   • Run: node receiver/server.js
   • Automatically uses X11 / Wayland uinput for seamless pointer and key control.
